# Telegram Agent MCP

Локальный MCP-сервер для двусторонней связи Codex с Telegram.

- `telegram_send_message` отправляет сообщения в настроенный чат;
- встроенный монитор принимает команды из Telegram и передаёт их Codex;
- `telegram_status` проверяет подключение и показывает актуальный префикс;
- смена префикса автоматически сбрасывает дочернюю Telegram-ветку агента.

## Быстрая установка

1. Распакуйте `telegram_agent_mcp.zip` в корень проекта. Папка должна называться `telegram_agent_mcp`.
2. Запустите из неё `setup.ps1` в PowerShell.
3. Введите токен Telegram-бота, ID чата и нужный префикс. Токен при вводе не отображается.
4. Подключите `dist/index.js` как локальный stdio MCP-сервер и перезапустите MCP-подключение.
5. Вызовите `telegram_status`.

Требуется Node.js 20 или новее. Установщик автоматически создаёт `.env`, каталог `data`, устанавливает точные зависимости из lock-файла и собирает TypeScript.

## Префикс

По умолчанию используется `cod`. Префикс должен быть отдельным первым элементом команды:

```text
cod тест связи
cod: тест связи
cod - тест связи
```

При префиксе `co` сообщение `cod тест` не принимается. Изменение `TELEGRAM_COMMAND_PREFIX` в `.env` применяется после текущего long-poll запроса, максимум примерно через 30 секунд. Сохранённая дочерняя ветка сбрасывается автоматически.

Полная инструкция: [INSTRUCTIONS.md](INSTRUCTIONS.md). Изменения версии: [RELEASE_NOTES.md](RELEASE_NOTES.md).

## Безопасная сборка архива

```powershell
.\build-package.ps1
```

Скрипт компилирует проект, проверяет состав и создаёт рядом с папкой `telegram_agent_mcp.zip`. В архив не попадают `.env`, токен, `data`, `node_modules` и машинно-зависимые пути.
